2. Données personnelles collectées

Lorsque vous utilisez le formulaire de contact présent sur le site, les données suivantes peuvent être collectées :

  • Nom
  • Adresse email
  • Numéro de téléphone
  • Message envoyé

La collecte de ces informations est nécessaire afin de pouvoir répondre aux demandes de renseignements, demandes de devis ou échanges concernant les prestations proposées par Amour de Fleurs.

3. Finalités du traitement

Les données collectées sont utilisées pour :

  • répondre aux messages envoyés via le formulaire de contact ;
  • traiter les demandes d'informations ;
  • établir un échange commercial avec les visiteurs intéressés par les prestations ;
  • assurer le suivi des demandes clients.

Les données personnelles collectées ne sont pas utilisées à des fins de prospection commerciale sans accord préalable.

4. Gestion du formulaire de contact

Le formulaire de contact du site est géré via le service Formspree.

Les informations saisies dans le formulaire sont transmises par Formspree puis envoyées par email à Amour de Fleurs afin de permettre le traitement de la demande. Les données transmises sont uniquement accessibles aux personnes habilitées à traiter les demandes.

5. Durée de conservation des données

Les données personnelles collectées via le formulaire de contact sont conservées pendant une durée maximale de 3 ans à compter du dernier échange avec la personne concernée. À l'issue de cette période, les données sont supprimées ou anonymisées.

6. Destinataires des données

Les données personnelles peuvent être accessibles uniquement par :

  • Amour de Fleurs SARL ;
  • les prestataires techniques nécessaires au fonctionnement du site (notamment Formspree, hébergeur et outils techniques).

Les données ne sont jamais vendues, louées ou transmises à des tiers à des fins commerciales.
